## Research Philosophy

- **Quantitative rigor:** Separate signal discovery from evaluation, document assumptions, and prioritize risk-adjusted performance over headline returns.
- **Hypothesis-driven research:** Define the economic or statistical intuition first, then test it using transparent, reproducible backtests.
- **Market structure awareness:** Study how liquidity, execution, volatility, and market microstructure can influence the behavior of apparent trading signals.
